Wanderlust

Демонстрационный сайт турагентства. Показывает каталог направлений, детали туров и отзывы.

Что умеет проект

  • Показывает фильтры и карточки туров.
  • Открывает информацию о туре в модальном окне.
  • Листает отзывы в отдельном слайдере.

Требования. Современный браузер. Для локального HTTP-сервера понадобится Python 3.

macOS

Подготовить Терминал

Установите Python 3 через пакет для macOS или свой менеджер пакетов.

Терминал
python3 --version

Скачать проект

Терминал
git clone https://github.com/mainstarkov/wanderlust.git
cd wanderlust

Или скачайте ZIP, распакуйте и откройте терминал в папке wanderlust-main.

Запустить

Терминал
python3 -m http.server 8000 --bind 127.0.0.1

Как проверить результат

Выберите направление, откройте карточку тура и пролистайте отзывы. Витрина демонстрационная, реальное бронирование не оформляется.

Адрес и режим работы. Откройте http://127.0.0.1:8000. Сервер можно остановить через Ctrl+C.

Исходники. index.html содержит секции страницы, script.js — фильтры и модальные окна, style.css — оформление.
