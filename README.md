# 🌍 Wanderlust

**[Попробовать демо](https://mainstarkov.github.io/wanderlust/)**

Демонстрационный сайт турагентства. Показывает каталог направлений, детали туров и отзывы.

[Открыть демо](https://mainstarkov.github.io/wanderlust/)

## Краткий путеводитель

- Показывает фильтры и карточки туров.
- Открывает информацию о туре в модальном окне.
- Листает отзывы в отдельном слайдере.

### Скачать и запустить

**Требования.** Современный браузер. Для локального HTTP-сервера понадобится Python 3.

Скачайте [ZIP исходников](https://github.com/mainstarkov/wanderlust/archive/refs/heads/main.zip) и откройте папку `wanderlust-main` **или** клонируйте репозиторий:

```sh
git clone https://github.com/mainstarkov/wanderlust.git
cd wanderlust
```

Выполните в этой папке:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```

В Windows PowerShell замените `python3` на `py -3`, если используете стандартный установщик Python.

Откройте http://127.0.0.1:8000. Сервер можно остановить через Ctrl+C.

### Проверить работу

Выберите направление, откройте карточку тура и пролистайте отзывы. Витрина демонстрационная, реальное бронирование не оформляется.

### Как устроено

`index.html` содержит секции страницы, `script.js` — фильтры и модальные окна, `style.css` — оформление.
