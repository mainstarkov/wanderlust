# 🌍 Wanderlust

Лендос для фейкового турагентства. Сверстал ради тренировки: тут есть поиск туров, попапы и слайдер отзывов.

**Глянуть можно тут:** [mainstarkov.github.io/wanderlust](https://mainstarkov.github.io/wanderlust/)

## Демо и адрес запуска

[Открыть GitHub Pages](https://mainstarkov.github.io/wanderlust/).

Откройте http://127.0.0.1:8000.

```sh
python3 -m http.server 8000 --bind 127.0.0.1
```
